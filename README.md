# Bank Customer Churn Prediction and Decision Support System

An end-to-end machine learning system predicting retail bank customer churn, optimizing contact thresholds for business retention profit, and delivering interactive decision support via Streamlit.

## Quickstart

```bash
# Set up virtual environment
python -m venv .venv
.venv\Scripts\Activate.ps1  # On Windows

# Install development dependencies and churn package
pip install -r requirements-dev.txt
pip install -e .

# Run linter and tests
ruff check .
pytest
```
